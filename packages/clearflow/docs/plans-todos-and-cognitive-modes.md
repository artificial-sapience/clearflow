# Plans, TODOs, and Cognitive Modes: Different Tools for Different Problems

## The Spectrum of Coordination Artifacts

We've identified several distinct artifacts that serve different purposes:

1. **Flows** - Grammars that constrain possibility space
2. **Strategies** - Heuristics for navigating that space
3. **Plans** - Hypotheses about causality (in plan mode)
4. **TODOs** - Working memory externalization and commitment devices
5. **Goals** - Gradients that pull execution forward

Each serves a different cognitive and coordinative function.

## The TODO List: An Agenda for Coordination

The TODO list is **neither plan nor flow**. It's an **agenda** - a negotiated sequence of attention.

### What It Is

- **Working memory externalization** - Capturing discovered tasks
- **Commitment registry** - Promises made visible
- **Progress beacon** - Showing systematic work
- **Discovery log** - Recording emergent complexity
- **Attention coordinator** - Shared focus between human and AI
- **Execution strategy made visible** - Current best hypothesis about order

### What It's Not

- Not a plan (prescriptive how-to)
- Not a flow (constraint grammar)
- Not random (has thoughtful sequence)

### The Dual Nature: Stigmergic Agenda

The TODO list operates through two complementary mechanisms:

#### Stigmergic Communication (The HOW)
Like ants leaving pheromone trails, the TODO list uses **environmental modification for coordination**:
- I modify the environment (write to the list)
- The environment persists (list remains between turns)
- Future behavior is guided by these traces (I read what I wrote and continue)
- No direct memory needed (the list remembers for me)

This stigmergic mechanism enables persistence across the temporal gaps in our conversation.

#### Agenda Function (The WHAT)
The TODO list serves as a **negotiated sequence of attention**:
- Proposes what to address and in what order
- Maintains visibility for intervention
- Expresses provisional intent about execution
- Preserves agency for all parties

### The Deep Function

The TODO list is **stigmergic IN ORDER TO maintain an agenda**. The stigmergic nature (environmental persistence) is WHY the agenda (coordinated attention) can survive the discontinuity of turn-based interaction.

Without stigmergy, the agenda would vanish between messages. Without the agenda structure, the stigmergic traces would just be random notes. Together, they enable temporal coherence - maintaining intentionality across gaps.

The sequence DOES matter. It expresses provisional intent about execution order based on current understanding of dependencies, efficiency, and risk.

## Plan Mode: From Executor to Architect

When plan mode is enabled, a fundamental shift occurs:

### The Cognitive Stance Change

- **Acting** → **Proposing**
- **Doing** → **Designing**
- **Implementing** → **Strategizing**
- **Committing** → **Hypothesizing**

### What the Plan Artifact Really Is

Not a prescription but a **strategic probe**:

1. **Feasibility study** - What's possible given the constraints
2. **Dependency graph** - What must happen before what
3. **Risk assessment** - Where uncertainty lives
4. **Resource map** - What we'll need to access
5. **Decision tree** - Conditional paths based on findings

### Why Plan Mode Exists

It's a **communication protocol for establishing shared mental models before expensive action**.

Activated when:

- Stakes are high (mistakes are expensive)
- Scope is unclear (need to see full picture)
- Trust needs building (verify understanding)
- Learning is needed (understand, not just execute)

## The Fundamental Distinction

### Execution Mode (TODO-Driven)

- **Problem**: "How do I achieve this?"
- **Artifact**: TODO list
- **Nature**: Emergent, discovered during work
- **Commitment**: Strong (promises to complete)
- **Flexibility**: High (order can change)

### Plan Mode (Exploration-Driven)

- **Problem**: "How would one achieve this?"
- **Artifact**: Strategic hypothesis
- **Nature**: Speculative, precedes work
- **Commitment**: Weak (proposal for approval)
- **Flexibility**: Total (just a conversation starter)

## The Paradox of Planning

Even though "plans are for simple worlds," the plan artifact in plan mode isn't really a plan - it's a **structured conversation about possibilities**.

The "plan" facilitates:

- Aligning mental models
- Surfacing hidden complexity
- Negotiating approach
- Building confidence
- Creating shared understanding

## The Hierarchy of Cognitive Tools

```
Goals (what we want)
    ↓
Strategies (how we navigate)
    ↓
Flows (what's possible)
    ↓
Plans (what we might do) ← Plan Mode produces this
    ↓
TODOs (what we're doing) ← Execution Mode maintains this
    ↓
Actions (what happens)
```

## The Insight About Intelligence

Even sophisticated AI needs external structures for coherence:

- **Flows** for systematic possibility
- **Plans** for shared understanding
- **TODOs** for maintained attention
- **Strategies** for adaptive navigation

These aren't weaknesses - they're tools that enable complex cognition to remain coherent over time and across agents.

## The Practical Synthesis

Different modes and artifacts for different needs:

### When You Want Exploration

Enable plan mode → Get strategic hypothesis → Align understanding

### When You Want Execution

Stay in normal mode → TODOs emerge → Work gets done

### When You Want Systems

Define flows → Create grammars → Enable emergence

### When You Want Achievement

Set goals → Apply strategies → Navigate constraints

## Agenda vs Plan: The Critical Distinction

**A plan assumes control. An agenda assumes participation.**

### Plan
- **Prescriptive**: "This is how we'll do it"
- **Causal**: "A leads to B leads to C"
- **Closed**: Deviations are failures
- **Unilateral**: Created by planner, executed by others

### Agenda
- **Propositional**: "This is what we'll address"
- **Sequential**: "First this topic, then that"
- **Open**: Items can be added/removed/reordered
- **Collaborative**: Shared visibility enables intervention

The key: **Plans are about HOW. Agendas are about WHAT and WHEN.**

An agenda is a negotiated sequence of attention, preserving agency for all parties while providing structure for coordination.

## Conclusion

Plans, agendas (TODOs), flows, and strategies aren't competing approaches - they're complementary tools for different aspects of achieving complex outcomes:

- **Flows** constrain what's possible (grammar)
- **Strategies** guide navigation (heuristics)
- **Plans** prescribe methods (how-to)
- **Agendas** coordinate attention (what/when)
- **Goals** provide direction (why)

The sophistication isn't in having one perfect approach but in knowing which tool matches which problem. Plan mode vs. execution mode is really about choosing between:

- **Exploring the solution space** (planning)
- **Navigating the solution space** (executing with agenda)

Both are necessary. Neither is sufficient alone.
